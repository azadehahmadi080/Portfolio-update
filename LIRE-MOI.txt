PORTFOLIO AZADEH AHMADI — DÉPLOIEMENT

Site statique complet en anglais (par défaut), français et dari/persan (RTL).
Orientation : candidatures internationales en master de Computer Science.

1. Décompressez le ZIP.
2. Si votre domaine change, adaptez les URL SEO avant publication :
   python configurer-domaine.py https://votre-domaine.fr
   (ou python3 selon votre ordinateur).
3. Téléversez tout le contenu du dossier décompressé à la racine de votre
   hébergement. index.html doit être à la racine. Aucune compilation.
4. Conservez les dossiers fr/, fa/, documents/ et toutes les images,
   le fichier styles.css, site.js, les favicons et les fichiers SEO.
5. Vérifiez les trois langues, les thèmes, les fenêtres de projet et le CV.

Pour tester localement, depuis le dossier décompressé :
   python -m http.server 8000
Puis ouvrez http://localhost:8000 dans votre navigateur.
Un double-clic sur index.html ne permet pas de tester tous les chemins.
